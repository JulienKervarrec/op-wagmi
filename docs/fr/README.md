# Parcours francais : op-wagmi (hooks React pour le pont OP Stack de Base)

Lecture pedagogique du depot base/op-wagmi : les hooks React au style wagmi construits au-dessus de op-viem pour les operations de pont entre Ethereum L1 et les chaines OP Stack (Base, Optimism).

Sommaire :

Chapitre 1 Presentation de op-wagmi. Chapitre 2 Les hooks de depot, simuler avant d ecrire. Chapitre 3 Resolution de chaine et validation des contrats. Chapitre 4 useProveWithdrawalArgs, orchestrer la preuve en hooks reactifs. Chapitre 5 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
